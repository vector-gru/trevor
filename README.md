# trevor
Play. Learn. Smile.  Trevor is an offline-first collection of fun and educational mini games for young children.

This project began as a tribute to my son, Trevor Noah. My goal is to create safe, joyful experiences that children can enjoy while learning through play.

Unlike many children's games, Trevor focuses on simplicity, creativity, and positive reinforcement. There are no ads, no internet requirement, and no pressure to win—just fun.

## Current Game

🎈 Balloon Pop

Pop colorful balloons, collect stars, enjoy cheerful sounds, and discover surprises.
